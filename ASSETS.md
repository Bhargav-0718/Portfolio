# Asset inventory

Every visual on the site is listed here with its provenance.

| Provenance    | Meaning                                                                              |
| ------------- | ------------------------------------------------------------------------------------ |
| **actual**    | A real artifact from the work: screenshot, original diagram, real photo.             |
| **original**  | Made for this site (SVG/CSS) to explain something. Not presented as a work artifact. |
| **generated** | AI-generated atmospheric artwork. Never used as evidence.                            |
| **awaiting**  | A placeholder slot waiting for the real asset.                                       |

## Folders

```
public/
├── cv/                résumé PDFs (registered in content/resumes.ts)
│   └── previews/      page images generated by `npm run resume:previews`
├── images/
│   ├── cases/         one folder per case slug: public/images/cases/<slug>/
│   ├── human-element/ event photos (only with permission to publish)
│   └── atmosphere/    textures and generated artwork
└── diagrams/          editable SVG diagrams
```
